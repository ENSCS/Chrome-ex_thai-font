# ฟอนต์ไทยอ่านง่าย (Thai Readable Font)

Chrome Extension ส่วนตัว เปลี่ยนฟอนต์ทุกเว็บเป็น **Sarabun** อ่านง่าย ตัวเลขชัด พร้อมปรับระยะบรรทัดและขนาด

## ฟีเจอร์
- เลือกฟอนต์ได้ในเมนู: **macOS** (system-ui → Thonburi → Sarabun) หรือ **Sarabun** (ฝังไฟล์ไว้ใน `fonts/`, ไม่พึ่งอินเทอร์เน็ต ไม่ติด CSP)
- ระยะบรรทัด 1.8 และขนาดตัวอักษรขั้นต่ำ 14px (ปรับที่ `MIN_PX` ใน `content.js`)
- ไม่แตะ icon font, `code`, `pre`, `svg`
- เมนูที่ไอคอน: สวิตช์ เปิด/ปิด, A− / A+ (ทีละ 5%, ช่วง 70–200%), ปุ่มลัด 100 / 110 ★ / 125 / 150
- ค่าเริ่มต้น: เปิดใช้งาน, ขนาด 110%
- ตอนปิดอยู่ ไอคอนมีป้าย `off` และคลิกไอคอนครั้งเดียวเพื่อเปิดทันที (ไม่ขึ้นเมนู)
- ค่าที่ตั้งเก็บใน `chrome.storage.local` ใช้ร่วมกันทุกแท็บ

> A+ / A− ใช้ CSS `zoom` ขยายทั้งหน้า ไม่ได้ขยายเฉพาะตัวอักษร

## ติดตั้ง
1. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้ (ถ้าได้ไฟล์ zip ให้แตกก่อน)
3. ปักหมุดไอคอนที่ปุ่มจิ๊กซอว์เพื่อใช้งานสะดวก

อย่าย้ายหรือลบโฟลเดอร์หลังติดตั้ง เพราะ Chrome อ่านไฟล์จากที่นั่นโดยตรง
หลังแก้โค้ด ให้กด reload ที่การ์ด extension แล้วรีเฟรชหน้าเว็บ

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | การตั้งค่า extension (MV3) ชื่อ/เวอร์ชัน |
| `content.js` | แทรก CSS ฟอนต์ + ระยะบรรทัด + zoom ลงทุกหน้า |
| `background.js` | สลับพฤติกรรมไอคอน (ปิด = คลิกเพื่อเปิด, เปิด = แสดงเมนู) และป้าย off |
| `popup.html` / `popup.js` | เมนูตั้งค่า |
| `fonts/` | Sarabun 300/400/500/600/700 (.ttf) |
| `icons/` | ไอคอน 16/32/48/128 |

## ปรับแต่ง
- ระยะบรรทัด: `line-height` และ `MIN_PX` ใน `content.js`
- ขนาดเริ่มต้นและปุ่มลัด: `DEF` และ `PRESETS` ใน `popup.js` (และ `DEFAULTS` ใน `content.js`)
- เปลี่ยนฟอนต์: เปลี่ยนไฟล์ใน `fonts/` และชื่อใน `content.js`
