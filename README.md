# ฟอนต์ไทยอ่านง่าย (Thai Readable Font)

Chrome Extension ส่วนตัว เปลี่ยนฟอนต์ทุกเว็บเป็น **Sarabun** อ่านง่าย ตัวเลขชัด พร้อมปรับระยะบรรทัดและขนาด

## ฟีเจอร์
- เลือกฟอนต์ได้ในเมนู: **macOS** (system-ui → Thonburi → Sarabun, ค่าเริ่มต้น), **Sarabun** (ฝังไฟล์ไว้ใน `fonts/`) หรือ **Google** (Google Sans + Sarabun จาก Google Fonts ต้องออนไลน์)
- ระยะบรรทัด 1.8 และปรับขนาดตัวอักษรอัตโนมัติตามฟอนต์เดิมของเว็บ (วัดความสูงอักษรเทียบกับฟอนต์ใหม่) แล้วใช้ขนาดตัวอักษรขั้นต่ำ ค่าเริ่มต้น **20px** (ตั้งได้ 14–36px ทีละ 2px, ปุ่มลัด 18/20/24/28)
- ไม่แตะ icon font, `code`, `pre`, `svg`
- เมนูที่ไอคอน: สวิตช์ เปิด/ปิดเฉพาะแท็บนี้, ปุ่มเลือกฟอนต์, A− / A+ และปุ่มลัดขนาด, สวิตช์ "ปรับเฉพาะฟอนต์" รายเว็บ
- **ทำงานแยกรายแท็บ**: ทุกแท็บเริ่มต้นปิด (ไอคอนมีป้าย `off`) คลิกไอคอนครั้งเดียวเพื่อเปิดเฉพาะแท็บนั้น ฟอนต์/ขนาดก็เป็นของแท็บนั้น (แท็บใหม่ใช้ค่าที่ตั้งล่าสุดเป็นค่าตั้งต้น) ปิด Chrome แล้วทุกแท็บกลับเป็นปิด
- ค่าเริ่มต้น: ฟอนต์ macOS, ขนาดขั้นต่ำ 20px, YouTube เปิดโหมดปรับเฉพาะฟอนต์

> ไม่มีการซูมหน้า A+ / A− ปรับเฉพาะขนาดตัวอักษร

## ติดตั้ง
1. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้ (ถ้าได้ไฟล์ zip ให้แตกก่อน)
3. ปักหมุดไอคอนที่ปุ่มจิ๊กซอว์เพื่อใช้งานสะดวก

อย่าย้ายหรือลบโฟลเดอร์หลังติดตั้ง เพราะ Chrome อ่านไฟล์จากที่นั่นโดยตรง
หลังแก้โค้ด ให้กด reload ที่การ์ด extension แล้วรีเฟรชหน้าเว็บ

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | การตั้งค่า extension (MV3) ชื่อ/เวอร์ชัน |
| `content.js` | แทรก CSS ฟอนต์ + ระยะบรรทัด + zoom ลงทุกหน้า |
| `background.js` | เก็บสถานะรายแท็บ (`chrome.storage.session`), สลับพฤติกรรมไอคอน (ปิด = คลิกเพื่อเปิด, เปิด = แสดงเมนู) และป้าย off |
| `popup.html` / `popup.js` | เมนูตั้งค่า |
| `fonts/` | Sarabun 300/400/500/600/700 (.ttf) |
| `icons/` | ไอคอน 16/32/48/128 |

## ปรับแต่ง
- ระยะบรรทัด: `line-height` และ `MIN_PX` ใน `content.js`
- ขนาดเริ่มต้นและปุ่มลัด: `DEFMIN` และ `PRESETS` ใน `popup.js` (และ `DEFAULTS` ใน `content.js`)
- เปลี่ยนฟอนต์: เปลี่ยนไฟล์ใน `fonts/` และชื่อใน `content.js`
